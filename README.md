QCM Battery Monitoring
Monitoring Electrolyte State of Health in Lithium-Ion Batteries Using Quartz Crystal Microbalance (QCM)

This repository contains the work developed for my Master's thesis at Uppsala University.

Project Overview

The objective of this thesis is to investigate the feasibility of using an FPGA-based measurement platform to analyze Quartz Crystal Microbalance (QCM) signals for monitoring electrolyte behavior in lithium-ion battery systems.

Commercial QCM-D systems provide highly accurate measurements but are often expensive and limited to laboratory environments. This project explores a low-cost alternative using the Red Pitaya platform together with custom signal-processing pipelines for resonance analysis and battery electrolyte monitoring.
